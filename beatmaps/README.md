# Beatmaps

Drop osu! beatmaps here: `.osz` archives or already-unpacked map folders. Song select unpacks each `.osz` into a folder of the same name the next time it opens (the `.osz` is left in place). Everything in this folder except this README is gitignored.

`.gdignore` stops the Godot editor importing map audio and images; the game reads this folder directly at runtime.
